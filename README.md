# Kaizen Coach (Web + Mobile)

A lightweight Expo application that helps users apply Kaizen methodology for continuous self-improvement.

## Features

- Set a single focused improvement goal.
- Break it down into tiny daily steps.
- Track completion progress visually.
- Write an end-of-day reflection.
- Get contextual coaching copy based on completion momentum.
- Works on iOS, Android, and the web from one codebase.

## Run locally

```bash
npm install
npm run web
```

For native simulators/devices:

```bash
npm run start
```
